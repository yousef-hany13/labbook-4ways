 # LabBook 4 Ways

CET322 Introduction to Cloud Computing - Course Project
"One Service, Four Ways": VM, Containers, Kubernetes, Hybrid.

## Service
A small lab booking service: web app + database.
Students reserve a lab or equipment slot, and the bookings list is displayed.

## Deployment Models
1. Virtual Machine (VirtualBox + Ubuntu + Nginx) -> see `vm/`
2. Containers (Docker) -> see `docker/`
3. Kubernetes (minikube) -> see `k8s/`
4. Hybrid (DB on VM, app on Kubernetes) -> see `hybrid/`
